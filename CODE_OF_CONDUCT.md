# Code of Conduct

Be kind, be direct, be constructive.

## What's expected

- Treat everyone with respect, regardless of background or skill level
- Give honest, useful feedback — and take it gracefully too
- Focus on the work, not on people
- Help others when you can

## What's not okay

- Harassment, insults, or personal attacks — in issues, PRs, or anywhere else
- Sharing someone's private info without permission
- Committing API keys, credentials, or real user data to the repo

## Data rules (this project uses live aviation data)

- No secrets in commits — use `.env.example` as a guide
- Don't log or store personally identifiable info from ADS-B feeds
- All data sources must stay free, open, and attributed per their licence

## If something goes wrong

Open a GitHub issue or reach out to the maintainers. We'll handle it fairly.
